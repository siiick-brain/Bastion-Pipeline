# Roadmap

This repository is laid out as a staged pipeline demonstration. The first pass establishes the repository control points and the documentation skeleton.

## Near-term work

- Build the FastAPI app and the test suite.
- Add Windows packaging automation and Pester coverage.
- Harden the Docker image and compare Trivy results.
- Wire the CI and security workflows.

## Later work

- Add GitOps manifests and ArgoCD validation.
- Add PKCS#11 signing and update verification tests.
- Add the firmware simulation suite.
- Capture the proof screenshots and record the run outcomes.
